# @civilcode/ui

Design system de CivilCode Studio. Primitivos React + TypeScript construidos sobre Radix UI headless + Tailwind v4. Ver [ADR-0008](../../docs/adr/0008-visual-identity.md).

## Contenido (Fase 1)

Mínimo de 15 primitivos a construir:

- `Button` (variants: primary, secondary, ghost, danger; sizes: sm, md, lg; loading state)
- `Input`, `Label`, `Textarea`, `Select` (con combobox)
- `Dialog`, `Toast`, `Tooltip`
- `Table` (con sort, filter, pagination, row selection, column resize)
- `Tabs`, `SplitPane`
- `CommandPalette` (⌘K)
- `Card`, `Badge`, `Avatar`, `Skeleton`

## Instalar (futuro)

```bash
pnpm install
pnpm --filter @civilcode/ui build
```
