# @civilcode/icons

Iconografía de dominio estructural — set propio de ~20 SVG components. Complementa a Lucide (iconografía genérica).

## Iconos planeados (Fase 1)

Elementos estructurales: `Beam`, `Column`, `Wall`, `Footing`, `Pile`, `Drilled Pier`, `Pile Cap`, `Joist`, `Slab`, `Node`, `Axis`, `Level`, `Diaphragm`, `Support`.

Acciones de ingeniería: `Load`, `Combination`, `Moment`, `Shear`, `DeformedShape`, `Sheet`.

## Instalar (futuro)

```bash
pnpm install
pnpm --filter @civilcode/icons build
```
